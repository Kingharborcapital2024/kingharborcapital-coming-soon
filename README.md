# King Harbor Capital — coming soon (GitHub Pages)

Public under-construction page. Gated demo stays local — no Demo link.

## Publish
1. Create public repo (or gh-pages branch)
2. Push this folder
3. Enable GitHub Pages (deploy from branch /docs or root)
4. Optional custom domain: after Picard/Mark DNS go, add CNAME `kingharborcapital.com` and set Squarespace Domains DNS A/AAAA to GitHub Pages IPs (keep Google MX untouched)

Without DNS: site lives at `https://<user>.github.io/<repo>/`
